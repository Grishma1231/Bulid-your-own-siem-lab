# 🛡️ Build Your Own SIEM Lab

## Overview

This project documents the design and implementation of a beginner-friendly Security Information and Event Management (SIEM) lab using virtual machines and open-source security tools. The objective is to understand how security events are collected, monitored, analysed, and investigated in a controlled environment.

The lab uses VMware Workstation to host Windows and Kali Linux virtual machines. Windows serves as the target system where security events are generated, while Kali Linux is used to simulate basic attack scenarios. Sysmon provides detailed Windows event logging, and Wazuh is used to collect, monitor, and analyse these logs.

---

## Objectives

- Build a virtual SIEM environment.
- Collect Windows security logs using Sysmon.
- Configure Wazuh for log monitoring.
- Simulate common cyberattacks in a safe environment.
- Analyse alerts generated by the SIEM.
- Understand the fundamentals of Security Operations Centre (SOC) monitoring.
